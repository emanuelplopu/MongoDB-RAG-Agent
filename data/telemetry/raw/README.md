# Raw Telemetry Data

**WARNING: This directory contains UNPROTECTED interaction data that may include PII (names, emails, addresses, etc.).**

This data is collected for trusted alpha/beta partner debugging only.
- NEVER commit these files to version control
- NEVER share without explicit consent
- Files are automatically rotated after the configured retention period
- To disable raw capture: set TELEMETRY_PII_MODE=protected_only
