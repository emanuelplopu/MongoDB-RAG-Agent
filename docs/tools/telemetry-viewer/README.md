# RecallHub Telemetry Viewer

## Overview

Standalone Electron desktop application for analyzing LLM interaction telemetry data generated by the RecallHub backend. It provides a rich interface for browsing, comparing, and visualizing telemetry records — including PII pseudonymization analysis — without requiring an active backend connection.

## Tech Stack

| Layer       | Technology                                |
|-------------|-------------------------------------------|
| Desktop     | Electron 33                               |
| UI          | React 18 + TypeScript                     |
| Bundler     | Vite 6 (dev server on port 11100)         |
| Styling     | Tailwind CSS 3 (dark/light/system theme)  |
| i18n        | i18next + browser language detector (EN/DE/RO) |
| HTTP        | Axios                                     |
| Markdown    | react-markdown + remark-gfm + rehype-highlight |
| Routing     | react-router-dom v7                       |

## Quick Start

```powershell
cd tools/telemetry-viewer
npm install
npm run electron:dev
```

The Vite dev server starts on port **11100** (auto-increments if busy) and Electron launches once the server is ready.

## Application Pages

### Import Page (`/import`)

Two data source modes:

**Local Files (Electron IPC)**
- Open individual `.jsonl` files via native file dialog
- Open a directory to scan for all `.jsonl` files
- Drag-and-drop `.jsonl` files directly onto the drop zone
- No backend required

**Remote API**
- Connect to a RecallHub backend instance (default: `http://localhost:11000`)
- Authenticate with an admin Bearer token
- Import by specific date or by date range (e.g. last 7 days)
- Choose between `protected` (pseudonymized) or `raw` data source

### Browser Page (`/` — default)

- **Record list** (left panel, 2/5 width): session-grouped records with filters:
  - Text search across prompt content
  - Model filter (orchestrator + worker models)
  - Session filter
  - Latency range (min/max)
  - Collapsible session groups
- **Record detail** (right panel, 3/5 width): full record inspection with collapsible sections:
  - Metadata (record ID, session, timestamp, model, profile)
  - Prompt (with PII highlighting and markdown rendering)
  - LLM Calls (per-call success, tokens, duration)
  - Search Operations
  - Tool Executions
  - Response (markdown rendered)
  - Timing (timeline waterfall visualization)
- **Color-coded latency indicators**: green (< 2s), yellow (2–5s), red (> 5s / error)
- **Multi-select** records for comparison

### Compare Page (`/compare`)

Two comparison modes:

**PII Comparison**
- Side-by-side protected vs raw response/prompt
- Color-coded PII entity pills with type labels
- PII summary bar showing entity counts per type

**Record Comparison**
- Select any two loaded records
- Metric delta badges: latency, tokens, model differences
- Inline diff highlighting between record contents

### Stats Page (`/stats`)

Computed entirely from loaded records (no separate API call):

- **Summary cards**: total records, average latency, total tokens, error rate, unique sessions, unique models
- **CSS-based charts** (no charting library dependency):
  - Latency distribution (bucketed: <1s, 1–2s, 2–5s, 5–10s, >10s)
  - Model distribution (percentage bars)
  - Token usage per model (prompt vs response)
  - Phase durations (analyze, plan, evaluate, synthesize, search, summarize, refine)
  - Records over time (by date)
  - PII statistics (entities by type)

## Data Sources

### Local Mode (Electron IPC)

The Electron main process exposes IPC handlers for filesystem operations:

| IPC Channel             | Description                                      |
|-------------------------|--------------------------------------------------|
| `dialog:openFile`       | Native file picker (multi-select, `.jsonl` filter) |
| `dialog:openDirectory`  | Native directory picker                          |
| `fs:readJsonlFile`      | Read and parse a JSONL file into records         |
| `fs:listJsonlFiles`     | List all `.jsonl` files in a directory with metadata |
| `fs:watchDirectory`     | Watch a directory for JSONL file changes         |

Context isolation is enabled; node integration is disabled. Communication goes through the preload script.

### Remote Mode (REST API)

Connects to the RecallHub backend telemetry endpoints:

- `GET /files` — list available telemetry files
- `GET /records` — fetch records by date/range
- `GET /search` — search records
- `GET /stats` — aggregated statistics

Authentication: admin Bearer token passed via Authorization header.

## PII Visualization

Telemetry records contain pseudonymized text with PII markers in the format:

```
[PII:TYPE]Alias[/PII]
```

The viewer renders these as color-coded inline pills:

| PII Type  | Color   |
|-----------|---------|
| PERSON    | Blue    |
| EMAIL     | Purple  |
| PHONE     | Green   |
| ADDRESS   | Orange  |
| COMPANY   | Teal    |
| IBAN      | Red     |

Hover tooltips display the PII type. The Compare page shows protected and raw text side-by-side with PII entities highlighted.

## Theme & Language

**Theme**
- Modes: system (default), light, dark
- Cycled via sidebar button (system → light → dark)
- Persisted to `localStorage` key: `telemetry-theme`

**Language**
- Supported: English, Deutsch, Română
- Auto-detected from browser/system language on first launch
- Persisted to `localStorage` key: `telemetry-language`
- Selectable via sidebar language dropdown
